A production-grade collection of modular Command Line Interfaces (CLIs) engineered with **Bashly** and **Docker Compose**. Developed at **Derak Cloud** to standardize, automate, and orchestrate the full lifecycle of distributed data clusters (**ClickHouse**, **ELK Stack**, **Hadoop HDFS/YARN**, and **PrestoDB**).

---

## 📌 Architectural Overview

Each CLI is a compiled single-file Bash executable generated by [Bashly](https://bashly.dannyb.co/). The CLI translates high-level commands into unified Docker Compose lifecycle actions, managing custom configurations, network bindings, and environment variables.
