## 🏛 Architectural Overview

Each CLI is a self-contained, single-binary Bash script generated by the **Bashly** framework. The CLIs translate declarative high-level commands into dynamic Docker Compose instructions, resolving configuration paths, host environments, and network bindings automatically.
